# Bangladesh Panorama: The Living Encyclopedia (Phase 1)
### অমর বাংলাদেশ: ডিজিটাল মিউজিয়াম

A stunning, modern, feature-rich digital platform and archive showcasing Bangladesh’s rich history, nature, biodiversity, culture, and modern achievements.

## Features (Phase 1)
1. **Immersive Hero Section**: Dynamic background, quick search, key statistics, and call-to-action.
2. **Introduction to Bangladesh**: National symbols, geography, demographics, and quick facts.
3. **History & Heritage**: Interactive chronological timeline from ancient Bengal, Language Movement (1952), Liberation War (1971), to the Modern Democratic Era.
4. **Nature & Biodiversity**: Sundarbans, Royal Bengal Tiger, river systems, flora & fauna.
5. **Culture & Traditions**: Festivals (Pohela Boishakh, Ekushey Book Fair), cuisine, folk art, and attire.
6. **Modern Achievements**: Digital Bangladesh, infrastructure megaprojects (Padma Bridge), space technology (Bangabandhu-1), and youth innovation.
7. **Interactive UI**: Modal viewports for detailed exhibit exploration, search filtering, responsive mobile navigation, and modern glassmorphism styling.

## Technologies Used
- HTML5 (Semantic markup, accessibility)
- CSS3 (Custom properties, glassmorphism, responsive grid/flex, animations)
- Vanilla JavaScript (Interactive tabs, modal handlers, search filtering, smooth scrolling)
- Google Fonts (Hind Siliguri for Bangla typography, Inter for English)
